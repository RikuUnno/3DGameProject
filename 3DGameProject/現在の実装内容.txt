3DGameProject 現状の仕組みまとめ

1. オブジェクト生成（Factory）
- ObjectFactory
 - RegisterCreator(key, creator): キーに対する生成関数を登録する
 - RegisterPrototype(key, prototype): プロトタイプ（Clone用）を登録する
 - Create(key, params): 登録された Creator があれば creator(params)で生成 / Prototype があれば Clone()する
 - IsRegistered(key): 登録済み確認
- 引数(params)の意味
 - VariantMap = std::unordered_map<std::string, std::string>
 - Spawn/SpawnAuto/Create に渡された params は最終的に GameObject::OnAcquire(params) に渡される（初期化用）
 - int/float 等は文字列で渡し、OnAcquire 側で stoi/stof 等で変換して使用する

2. オブジェクト再利用（Pool）
- ObjectPool
 - Acquire(): freeList にあれば再利用、なければ creator_()で新規生成
 - Release(obj): freeList に戻す。freeList が maxSize を超えていれば delete
 - SetMaxSize(max): 上限変更、超過分は delete
 - Clear(): 未使用ストック（freeList）を全 delete
 - TrimUnused(maxIdleSeconds, nowSeconds): lastReleasedSecから一定秒以上未使用のストックを delete（戻り値: 削除数）
 - Size(): freeList の現在数（未使用ストック数）
- pool数 / poolSize
 - pool数: ObjectManager が保持しているプール種類（key）の数
 - poolSize: 各プールの未使用ストック上限（maxSize）

3.生成＋所有＋プール連携（ObjectManager）
- ObjectManager
 - Spawn(key, params)
 - 該当プールがあれば Acquire()して取得
 - 無ければ ObjectFactory::Create(key, params)で生成
 -取得後に必ず GameObject::OnAcquire(params) を呼ぶ
 - poolKey を設定（プール経由の場合）
 - ownerSceneId を設定（現在シーンID）
 - Release(obj)
 - obj->poolKey が空でない: OnRelease() を呼んでプールへ返却
 - obj->poolKey が空: OnDestroy() を呼んで delete
 - UpdateAll()/DrawAll(): 管理中 objects_ 全体へ Update/Draw（スナップショット方式）
 - FindById/RemoveById
- Poolメンテ（未使用ストック対象）
 - ClearPool(key)
 - TrimPoolUnused(key, sec)
 - TrimAllPoolsUnused(sec)
 - UnregisterPool(key): 使用中が残っていれば失敗し、freeList は破棄してプール削除
- シーン連携
 - SetCurrentSceneId(id), CurrentSceneId()
 - ReleaseBySceneId(sceneId): 指定 sceneId の生成物を一括 Release
- Debug（Debugビルドのみ）
 - DebugDraw(): 現在オブジェクト数、総生成数(取得回数)、総削除数(破棄回数)、プール数、未使用ストック数などを日本語表示

4. シーン内生成物だけを操作（ObjectController）
- ObjectController
 - Spawn(key, params): ObjectManager::Spawn を呼び、生成物を Controller 内に登録
 - SpawnAuto(key, creator, poolSize, params):
 - 未登録なら Factory登録 + Pool登録（初回のみ）
 -その後 Spawnして Controller に登録
 - UpdateAll()/DrawAll(): Controller が管理する生成物だけ Update/Draw
 - Release(obj)/ReleaseAll(): Controller 管理生成物を返却

5. Scene管理（SceneManager）
- SceneManager
 - ChangeScene/PushScene/PopScene/RequestChange/ProcessPendingChanges
 - シーン終了時の自動回収
 - ChangeScene() の前に ObjectManager::ReleaseBySceneId(currentSceneId) を呼ぶ
 - PopScene()でも同様に回収する
 - CurrentSceneId(): 現在シーンIDを取得

6. Mainループ側の自動処理（Main.cpp）
- プールの自動掃除
 -1秒ごとに ObjectManager::TrimAllPoolsUnused(10秒) を呼び、未使用ストックを自動 delete
- デバッグ表示
 - Debugビルドのみ、ObjectManager::DebugDraw を左下に表示（全シーン共通）

補足
- シーン移動しただけでは自動でプールに戻らない（Releaseが必要）問題に対し、ownerSceneId による一括回収を導入済み。
- プールに戻ったオブジェクトはすぐ deleteされない。maxSize 超過、Clear/Trim、または自動Trim条件に達した場合に deleteされる。
